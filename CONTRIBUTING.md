# Contributing to M-Pesewa

First off, thank you for considering contributing to M-Pesewa! It's people like you that make M-Pesewa such a great tool for emergency micro-lending across Africa.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct:
- Be respectful and inclusive
- Exercise empathy toward other community members
- Use welcoming and inclusive language
- Be collaborative
- Focus on what's best for the community
