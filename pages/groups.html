📋 Group Creation Rules

  • ✅ Minimum 5 members to create a group
  • ✅ Maximum 1,000 members per group
  • ✅ One admin/founder per group
  • ✅ Groups are country-locked (no cross-border members)
  • ✅ Invitation or referral only
  • ✅ Admin can set group-specific rules
  • ✅ Admin can remove members (with 24-hour notice)
  • ✅ Groups can be public or private

⚙️ Group Management

  • 🔧 Admin mobilizes and moderates members
  • 🔧 Admin invites first 5 members
  • 🔧 Members can invite others (if allowed by admin)
  • 🔧 Each group has a unique nickname
  • 🔧 Country badge displayed on all groups
  • 🔧 Budget visibility to members
  • 🔧 Admin can view all lending activities
  • 🔧 Admin can mediate disputes
⚠️

Important Group Rules

• No cross-group lending - lenders can only lend within their own groups
• No cross-country lending - groups are country-isolated
• Borrower maximum: 4 groups total (good rating required for additional groups)
• Default in one group affects rating across all groups
• Groups can set minimum rating requirements for members
