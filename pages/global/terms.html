1. PLATFORM ROLE (VERY IMPORTANT)

  1. M-Pesewa is not a bank, not a lender, not a borrower, and does not hold user funds.
  2. M-Pesewa is a technology platform that:
    • Enables verified users to organize into groups
    • Enables lenders and borrowers to interact inside their groups
    • Provides ledger tracking, record keeping, and coordination tools
  3. All money transfers happen directly between users using their own chosen payment methods.
  4. M-Pesewa does not guarantee repayment, performance, or behavior of any user.

2. COUNTRY & GROUP STRUCTURE

  1. Every user belongs to one country.
  2. Every group belongs to one country.
  3. No cross-country lending or borrowing is allowed.
  4. All lending and borrowing happens inside groups only.
  5. Group access is by invitation, referral, or admin approval.

📌 STRICT HIERARCHY (NON-NEGOTIABLE)

Global → Countries → Groups → Lenders → Borrowers (Ledgers)
This hierarchy enforces country isolation, group isolation, and strict access controls.

3. USER ROLES

A user may act as:

  • Borrower (requesting loans)
  • Lender (offering loans — subscription required)
  • Group Admin (moderating group activities)

A user may change roles, but cannot be borrower and lender in the same loan at the same time.

💡 DUAL ROLE SYSTEM

Users can have both borrower and lender profiles. To switch roles, user must:
1. Log out
2. Start new registration for the desired role
3. Maintain separate profiles for each role
