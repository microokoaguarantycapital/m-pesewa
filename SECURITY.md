# M-Pesewa Security Policy

## 🔒 Overview

M-Pesewa is a **real fintech platform** handling sensitive financial data through client-side operations. This document outlines our security practices, vulnerability reporting procedures, and user protection measures.

## ⚠️ Reporting Security Issues

### **DO NOT DISCLOSE SECURITY VULNERABILITIES PUBLICLY**

If you discover a security vulnerability in M-Pesewa:

1. **Email**: security@mpesewa.com
2. **Subject**: "Security Vulnerability Report - M-Pesewa"
3. **Encryption**: Use PGP key (below) for sensitive reports
4. **Response Time**: We will acknowledge within 24 hours
